# Дипломний проєкт: аналіз ринкових процесів + Telegram-бот + міні-застосунок

## Структура
| Файл | Призначення |
|---|---|
| `config.py` | усі налаштування (активи, періоди, порт, токен, URL) |
| `database.py` | SQLite, денні ряди |
| `data_sources.py` | CoinGecko (крипта) і НБУ (валюти) |
| `collector.py` | збір поточних курсів і історії |
| `indicators.py` | SMA, EMA, RSI |
| `forecasting.py` | методи прогнозу (реєстр `METHODS`) |
| `evaluation.py` | walk-forward перевірка: MAE, RMSE, MAPE, напрямок |
| `analysis.py` | готовий аналіз активу для бота й міні-застосунку |
| `charts.py` | графіки для тексту роботи (папка `charts/`) |
| `api.py` + `webapp/index.html` | веб-сервер і сторінка міні-застосунку |
| `bot.py` | команди бота + кнопка міні-застосунку |
| `run.py` | усе разом: БД + фоновий збір + веб-сервер + бот |
| `main.py` | лише дослідження (таблиці й графіки), без бота |

## Встановлення
```
pip install -r requirements.txt
```

## Запуск лише дослідження (для Розділу 4)
```
python main.py
```

## Запуск бота з міні-застосунком
Telegram відкриває міні-застосунок лише за адресою **HTTPS**, тому локальний
сервер треба "виставити" в інтернет тимчасовою адресою.

1. Токен бота: @BotFather -> `/mybots` -> ваш бот -> API Token.
2. Запустіть тунель (один із варіантів):
   * ngrok: `ngrok http 8000` -> скопіюйте адресу `https://....ngrok-free.app`
   * cloudflared: `cloudflared tunnel --url http://localhost:8000`
3. Задайте змінні та запустіть (PowerShell):
```
$env:BOT_TOKEN="ваш_токен"
$env:WEBAPP_URL="https://ваша-адреса-тунелю"
python run.py
```
4. У Telegram: `/start` -> кнопка «Відкрити аналітику», або синя кнопка
   «Аналітика» біля поля вводу.

Адреса тунелю змінюється при кожному запуску ngrok/cloudflared (безкоштовна версія),
тому `WEBAPP_URL` треба оновлювати. Для постійної адреси викладіть проєкт
на хостинг із HTTPS (Render, Railway, PythonAnywhere) -- код від цього не змінюється.
